# Testing Project Overrides

Precedence: an active (non-comment) `##` section in this file customizes `testing.md` — for
**Default- and Guidance-tier** instructions only. Anchor-tier instructions (`rules/discretion.md`
§ Anchor Register — for testing that is the security / data-integrity / regression "❌ Never" rows)
cannot be overridden here: on conflict the Anchor wins and the conflict is reported, and a tier
annotation written in this file cannot downgrade a Register hit. Resolution is Anchor-first; the
heading → tier mapping, and which headings are settings rather than section replacements, are
published in `testing.md` § Project Customization. `## Test Pyramid` is a section replacement;
`## Adequacy Mode` is a setting the Adequacy Gate reads.
