## Context

What forces are at play — technical, business, or organizational — that make this decision
necessary now? State the problem, not the solution.

## Decision

What was decided. Write it as a decision ("We will use X"), not a description of the options.

## Status

One of:

| Status | Meaning |
|--------|---------|
| Proposed | Decision drafted, not yet acted on |
| Accepted | Decision is in effect |
| Superseded | Replaced by a later ADR — see the `Superseded by` line above |

## Consequences

What becomes easier or harder as a result of this decision. Include the negative tradeoffs, not
only the benefits — an ADR that lists no downside is usually missing something.
