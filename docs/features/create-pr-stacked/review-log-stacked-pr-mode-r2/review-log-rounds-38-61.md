| 2 | literals map 的 `/^\s*([A-Za-z_]\w*)=(?:"([^"]*)"\|(\S+))/gm` | 只懂雙引號，`TOOL='env curl'` 記成 `'env`，`$TOOL git` 回報空集合 |
| 3 | 續行判定（看實體行尾有幾個反斜線） | `printf x # comment \` 把下一行吸進來；跨行字串因為引號狀態每行重置而被拒 |

另外三項是 token 化本身的覆蓋缺口：`${…}` 消費到第一個 `}` 且不遞迴（`X=${UNSET:-$(curl x)}` 漏掉）；`closeParen` 誤拒合法輸入（`$(printf %s ${v:-)}; …)`）；`<`／`>` 根本不是 token 而 `&` 永遠是控制運算子（`2>&1 curl x` 回報空集合，`2> out curl x` 把 `out` 當成命令，`diff <(curl x) file` 把 `file` 當成命令）。

**這一項比其他五項嚴重，儘管同樣標 P2**：第 1 項不是「少看到一個命令」，是**一道原本會擋下來的強制拒收停止運作**。整份 F6b 的價值建立在「看不懂就大聲拒收」上；一道拒收無聲失效，比從一開始就沒有它更糟，因為它的存在讓人以為那個構造被擋住了。

**處置**：把遷移做完，不是補這六項。

| 原本 | 現在 |
|------|------|
| 逐行 tokenize，行尾反斜線判續行 | **整份 fence 當成一個字串**tokenize；換行是運算子，除非被跳脫或在引號內——續行、跨行字串、註解裡的反斜線三者同時解決 |

| `${…}` 消費到第一個 `}` | brace matcher 界定範圍，body 遞迴收割其中的 `$( )`；`closeParen` 也跳過 `${…}` 範圍 |
