## Background

`/smart-commit` 的 AI attribution 防護僅依賴行為層 regex sanitization（SKILL.md:147-157），但 Claude 系統行為有時會繞過 skill 指令，導致 `Co-Authored-By: Claude` 殘留在 commit message 中。現有 `commit-msg-guard.sh` 為選裝 git hook，無法保證覆蓋率。此外，SKILL.md 與 guard script 的 regex 方言不一致（PCRE vs BRE），可能產生 false negative。

## Requirements

- 在 `--execute` 模式的 Step 5c 加入 **runtime validation**：寫入 temp file → `grep -Ei` 驗證 → 通過後 `git commit -F`
- 實作 `--ai-co-author` **窄白名單**：僅允許精確格式 `Co-Authored-By: Claude <noreply@anthropic.com>`，其他 AI pattern 即使啟用旗標仍 block
- Post-commit 洩漏偵測改為 **hard stop**：發現 forbidden pattern 立即停止所有剩餘 commit groups
- 正規化 `commit-msg-guard.sh` regex 為 **POSIX ERE**（`grep -E`），作為唯一 canonical source
